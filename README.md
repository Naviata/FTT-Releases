# Flynn's Terrain Tools

A free toolkit for building DayZ terrains alongside TerrainBuilder — forests, roads, fences, rivers,
powerlines, terrain holes, a 3D flythrough and more. Nothing is behind a paywall.

## Download

**[Latest release →](https://github.com/Naviata/FTT-Releases/releases/latest)**

Download `FlynnsTerrainTools.exe` from the release. It is the whole program — no installer, nothing
to unpack. Put it anywhere and run it.

**Needs:** 64-bit Windows 10 or 11, DayZ Tools, and a mounted P: work drive.

The first time you run a new version, Windows may say *"Windows protected your PC"* because the exe
is not code-signed. Click **More info**, then **Run anyway**.

FTT checks this page once a day and shows a notice in its status bar when a new version is out, so
you only ever need to download it once.

## Starter terrain

A ready-made terrain to start from is on
[FTT-Samples](https://github.com/Naviata/FTT-Samples/releases). Extract it to
`P:\FTT_TerrainSample`, then in FTT: *Terrain Creation → Create Terrain Source → From the FTT sample*.

## This repository
